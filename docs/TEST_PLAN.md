# 测试计划

## 1. 当前状态与方法

第 2–7 节为整体验收清单，第 9 节汇总已有验证结果，第 10 节列出当前认证模块仍需执行的真实存储验收。自动化回归通过不代表所有阶段已完成。

测试原则：

- 连续天数算法使用可注入 `Clock` 做确定性测试。
- 数据库唯一约束、事务和 Redis 使用真实 MySQL/Redis 验证。
- UniApp H5 使用真实 REST API 做端到端验收。
- 不用 H2、内存 Map 或前端 Mock 代替真实 MySQL/Redis 的核心验收。
- 测试使用独立数据库、Redis 库和测试账户，不污染正式演示数据。

本计划分为“必做测试”和“可选高级测试”。项目先通过必做测试，再视时间补充高级验证。

## 10. 当前认证模块的真实存储待验收项

以下均未完成真实 MySQL/Redis 联调。应使用隔离数据库、独立 Redis 测试环境及测试账户；应用启动不再自动插入账户，测试数据由测例在测试事务内准备。测试报告不得记录明文密码或完整 Token。

| 场景 | 验收要求 |
| --- | --- |
| 登录及当前用户 | 使用真实 BCrypt 用户登录；完整响应包含 token、tokenType、expiresIn、user；ID 为字符串，资料不含密码哈希 |
| 输入与错误凭证 | 用户名规范化、ASCII 长度和密码 UTF-8 字节限制生效；非法参数返回 40001；合法格式的错误凭证返回 40102，不产生会话 |
| 实际存储与过期 | 检查摘要键、用户 ID 字符串及真实 TTL；重复查询不续期；自然到期后返回 40101，不能从 MySQL 恢复原会话 |
| 登出与多会话 | 当前键被删除，原令牌再次访问或登出返回 40101；同一用户的其他会话仍有效 |
| 并发登出 | 删除前已完成鉴权的请求允许都返回 200；删除后才鉴权返回 40101；最终当前 Session 不存在，其他会话不受影响，不要求恰好一个 200 |
| 用户已删除 | 受保护请求拒绝身份并撤销当前会话；清理 Redis 失败返回 50301，不放行 |
| 损坏会话 | 非整数、非正数及超出 Long 范围的身份值被清理后返回 40101 |
| Redis 与 MySQL 故障 | Redis 读、写、删除故障返回 50301；数据库连接故障返回 50302，不误删正常会话 |
| 演示 SQL | 在隔离演示库手工执行，真实 BCrypt 登录成功；重复执行不覆盖已有用户密码，不作为并发注册验收 |
