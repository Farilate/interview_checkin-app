# 测试计划

## 1. 当前状态与方法

第 2–7 节为整体验收清单，第 9 节汇总已有验证结果，第 10 节列出已完成的认证模块真实存储验收范围。阶段 1–8 的全部真实验收已于 2026-09-20 完成，统一记录见第 18 节；Phase 9 第一阶段的 H5 登录闭环、真实联调和 CORS 已完成（见第 19 节）；Habit 列表与创建前端已实现（见第 20 节），真实 Habit 联调、后续打卡页面与最终交付仍待完成。自动化执行记录与真实验收结论分别记录。

测试原则：

- 连续天数算法使用可注入 `Clock` 做确定性测试。
- 数据库唯一约束、事务和 Redis 使用真实 MySQL/Redis 验证。
- UniApp H5 使用真实 REST API 做端到端验收。
- 不用 H2、内存 Map 或前端 Mock 代替真实 MySQL/Redis 的核心验收。
- 测试使用独立数据库、Redis 库和测试账户，不污染正式演示数据。

本计划分为“必做测试”和“可选高级测试”。项目先通过必做测试，再视时间补充高级验证。
